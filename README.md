# Система заселения студентов в общежития

## О проекте

Проект посвящен системному анализу процесса заселения студентов в общежития университета и разработке требований к информационной системе, автоматизирующей данный процесс.

Основная цель проекта — описать предметную область, выявить проблемы существующего процесса, сформировать требования к будущей системе и подготовить аналитические артефакты, необходимые для дальнейшего проектирования и разработки.


---

## Бизнес-задача

Текущий процесс заселения студентов сопровождается большим количеством ручных операций:

* бумажный документооборот;
* очереди при подаче документов;
* длительная проверка документов;
* отсутствие прозрачного статуса обработки заявления;
* высокая нагрузка на паспортистов и администрацию общежитий;
* сложности миграционного учета иностранных студентов.

Предлагаемая система автоматизирует основные этапы заселения: от подачи заявления до оформления договора и регистрации.

## Что было сделано

В рамках проекта были выполнены следующие задачи системного анализа.

### Анализ предметной области

* изучен существующий процесс заселения студентов;
* выделены основные сущности предметной области;
* построена UML-диаграмма классов предметной области;
* определены взаимосвязи между объектами системы.

---

### Анализ заинтересованных сторон

Выделены основные участники процесса:

* Студент;
* Паспортист;
* Комендант;
* Сотрудник деканата.

Для каждой роли определены цели, ответственность и взаимодействие с системой.

---

### Формирование требований

Определены:

* бизнес-проблемы;
* цели автоматизации;
* функциональные возможности системы;
* ограничения;
* показатели качества;
* пользовательские потребности.

Сформирована концепция будущего продукта.

---

### Моделирование вариантов использования (Use Case)

Выполнено:

* выявление акторов;
* построение диаграммы вариантов использования;
* детальная спецификация основных сценариев.

Основные бизнес-процессы:

* подача заявления;
* загрузка документов;
* проверка документов;
* запись к паспортисту;
* подтверждение права на заселение;
* распределение по комнатам;
* оформление договора;
* оформление регистрации;
* ведение миграционного учета.
